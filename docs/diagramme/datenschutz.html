Datenschutz – deine Daten, deine Kontrolle

Wer Symtora nutzt, kann jederzeit alles mitnehmen oder löschen – direkt in der App unter «Daten».

Was du jetzt tun kannst

Daten exportieren

Alles, was über dich gespeichert ist, kommt als Datei aufs Handy – zum Speichern, Teilen oder Mailen.

App→ Server sammelt alles→ ✓ Datei

Gesundheitsdaten löschen

Alle Einträge und KI-Einschätzungen sind weg. Dein Konto bleibt, du kannst neu anfangen.

App→ Server löscht→ ✓ Einträge weg

Konto löschen

Konto und alle Daten sind endgültig weg. Du wirst auf allen Geräten sofort abgemeldet.

App→ Server löscht alles→ ✓ Konto weg
Vorher → Nachher

Vorher

  • «Löschen» leerte nur die Anzeige – die Daten blieben auf dem Server und tauchten wieder auf.
  • Seine Daten mitnehmen ging nicht.
  • Ein Konto ganz löschen ging nicht.

Nachher

  • Zuerst löscht der Server – erst dann zeigt die App «gelöscht». Klappt es nicht, sagt die App das ehrlich.
  • Export als Datei mit einem Tipp.
  • Ein gelöschtes Konto meldet sofort überall ab, statt noch bis zu 7 Tage angemeldet zu bleiben.
Das galt schon vorher: Die KI und die Spracherkennung laufen auf dem eigenen Server – nichts geht an fremde Firmen. Sprachaufnahmen werden nie gespeichert.
